# Security audit: developer scripts and CI workflows (#476, part of #473)

Previous pass: #221 (scripts quoted, no `eval`, no `subprocess` at the time). Workflows were never audited.
Diff the next pass against this file.

## Method and limits
- Read every call site; grep for `shell=True`, `eval`, `curl | sh`, `${{ github.event.* }}` / `${{ inputs.* }}` inside `run:`, `pull_request_target`.
- `shellcheck` is not installed on the audit machine, so shell scripts were checked with `bash -n` plus a grep for unquoted `$var` expansions, not with shellcheck. Run shellcheck on a machine that has it before relying on the shell rows.
- `.github/dependabot.yml` is **missing**. Not added here (scheduled bot PRs are a separate product choice, out of scope).

## Findings fixed in this PR
| # | Finding | Fix | Gate |
|---|---|---|---|
| 1 | `scripts/uat-server.py` accepted any POST to `127.0.0.1`. A web page open in the owner's browser could send a simple cross-origin POST (`Content-Type: text/plain` body is still parsed as JSON) and trigger `gh issue create` / `gh issue comment` and UAT.md writes. A DNS-rebinding hostname would also have been same-origin. | Per-run random token (`secrets.token_urlsafe`) embedded in the served page and required in an `X-UAT-Token` header on every POST (custom header forces a CORS preflight the server never approves). `Host` must be `127.0.0.1`/`localhost` on GET and POST. `--export` output carries no token (it is read-only). | `HttpTests.test_post_without_token_is_rejected_and_files_nothing`, `test_post_with_foreign_host_is_rejected_even_with_token` in `scripts/test_uat_server.py` |
| 2 | `checks.yml`, `macos-tests.yml`, `sync-deploy.yml`, `test.yml` had no top-level `permissions:` (token got the repo default). | Added `permissions: contents: read` to each. None of them calls the GitHub API with the token. | `scripts/checks/check-workflow-permissions.sh` (job `workflow-permissions` in `checks.yml`), self-test `test_check_workflow_permissions.sh` proves it fails on a workflow with no top-level block and on one with only job-level `permissions:` |
| 3 | Tracked scratch files at repo root. | Removed (see below); `/*.log`, `/stdout.txt`, `/stderr.txt`, `/*.patch` added to `.gitignore`. | `.gitignore` |
